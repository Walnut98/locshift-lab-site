# 华为 P40 模拟定位教程

## 1. 安装

1. 用手机浏览器打开：https://walnut98.github.io/locshift-lab-site/downloads/FakeTraveler-2.3.2.apk
2. 下载完成后点击 APK 安装。
3. 如果华为提示“未经检测”或“纯净模式拦截”，选择“继续安装”，或临时关闭纯净模式的增强防护。
4. 允许浏览器或文件管理器安装未知来源应用。

版本：FakeTraveler 2.3.2，支持 Android 5.0 及以上，无需 Root。

## 2. 开启开发者选项

1. 打开“设置 → 关于手机”。
2. 连续点击“版本号”7 次。
3. 输入锁屏密码。
4. 返回“设置 → 系统和更新 → 开发人员选项”。

## 3. 授权模拟位置

1. 在“开发人员选项”中找到“选择模拟位置信息应用”。
2. 选择“Fake Traveler”。
3. 打开 Fake Traveler，允许位置权限。

## 4. 设置位置

1. 在 Fake Traveler 顶部搜索框输入地点名称并点击搜索。
2. 地图移动后，长按目标位置。
3. 确认经纬度显示后，点击“Apply（应用）”。
4. 按钮变成“Stop（停止）”表示模拟已运行。
5. 完全退出高德地图，再重新打开并点击定位。

也可以直接输入纬度 Lat 和经度 Long，再点击“Apply”。

## 5. 停止并恢复真实定位

打开 Fake Traveler，点击“Stop（停止）”。如果按钮已经是“Apply”，说明模拟定位没有在运行。必要时重启手机。

## 6. 常见问题

- 提示“Mocked location not applied”：回到开发人员选项，确认“选择模拟位置信息应用”已经选中 Fake Traveler。
- 位置来回跳动：在系统“位置信息”中关闭 Wi-Fi 扫描和蓝牙扫描后再试。
- 后台一会儿就停止：在“设置 → 应用 → 应用启动管理”中关闭 Fake Traveler 的自动管理，允许后台活动。
- 搜索不到中文地名：可先搜索附近较大的车站、商场或道路，再在地图上长按准确位置。
- 银行、考勤和游戏应用可能检测模拟位置；本应用不绕过这类检测。
